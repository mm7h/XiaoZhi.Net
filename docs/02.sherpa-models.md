# Sherpa-onnx 本地模型

### 再次感谢 [k2-fsa/sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) 开源。

当前项目的本地模型都采用 `sherpa-onnx` 实现的，通过配置文件设置后，可以作为服务端的兜底推理模型。

## 模型下载

Windows 使用 [Download-SherpaModels.ps1](../scripts/Download-SherpaModels.ps1)，Linux/macOS 使用 [Download-SherpaModels.sh](../scripts/Download-SherpaModels.sh)。两个入口共用 [SherpaModels.psv](../scripts/SherpaModels.psv) 中的 33 个模型及文件映射，均无需 Python。

Windows（PowerShell 7）：

```powershell
# 下载指定模型到仓库 models 目录
pwsh -File .\scripts\Download-SherpaModels.ps1 -Models Silero,OnlineParaformer,Kokoro

# 下载全部模型；模型总量很大，请先确认网络和磁盘空间
pwsh -File .\scripts\Download-SherpaModels.ps1 -All

# 下载到自定义目录，并保留下载的压缩包
pwsh -File .\scripts\Download-SherpaModels.ps1 -Models SenseVoice -Destination D:\XiaoZhiModels -KeepArchives
```

Linux/macOS（Bash 3.2 及以上）：

```bash
# 下载指定模型
bash ./scripts/Download-SherpaModels.sh --models Silero,OnlineParaformer,Kokoro

# 下载全部模型
bash ./scripts/Download-SherpaModels.sh --all

# 下载到自定义目录，并保留压缩包；路径含空格时请加引号
bash ./scripts/Download-SherpaModels.sh --models SenseVoice --destination "$HOME/XiaoZhi Models" --keep-archives
```


<details>
<summary>下载说明</summary>

所需工具：

| 平台 | 下载 | 解压 |
| --- | --- | --- |
| Windows | PowerShell `Invoke-WebRequest`；失败时使用 `curl.exe`，也可加 `-UseCurl` | 优先使用通过能力检查的 `tar.exe`，否则使用 [7-Zip](https://www.7-zip.org/)。部分 Windows 自带 tar 缺少 bzip2 支持，此时需要安装 7-Zip；脚本会查找 PATH 和标准安装目录，也可用 `-SevenZipPath "C:\Tools\7-Zip\7z.exe"` 指定 |
| Linux | `curl` | GNU tar 与 `bzip2`；精简系统可能需要通过包管理器安装，例如 Debian/Ubuntu：`sudo apt-get install curl tar bzip2` |
| macOS | 系统自带 `curl` | 系统自带 BSD tar，通常支持 bzip2；脚本兼容系统自带 Bash 3.2 |

脚本会在正式下载前用内置微型归档检查 `.tar.bz2` 支持，缺少工具时立即停止。Windows 也可通过 Git Bash 运行 `.sh` 入口，使用 Git Bash 自带的工具。请保留整个 `scripts` 目录，入口需要读取共用清单及能力检查归档。

- 目标目录已有完整模型时，脚本会跳过它。目录不完整时，脚本会停止以保护已有文件；确认需要重新下载时，显式添加 `-Force` / `--force`。
- `-KeepArchives` / `--keep-archives` 会在目标目录的 `.sherpa-archives` 下保留压缩包。下载中断后的不完整目录需要加 `-Force` / `--force` 重新下载，不支持断点续传；重新下载时不会复用可能不完整的旧压缩包。
- 服务从运行时工作目录下的 models 读取模型。默认下载到仓库根目录的 models；如果从示例项目目录或发布目录启动服务，请用 `-Destination` / `--destination` 指定该目录下的 models。
- 未指定模型时只显示列表，不会下载任何内容。
- ZipVoice、Pocket 的参考音频/文本仍需自行提供，脚本会提示缺少的文件。
- 模型下载后会自动解压到仓库的 `models` 目录下，目录结构如下：
```text
models/{vad|asr|tts}/{模型名-kebab-case}/
```
- 模型由用户部署时自行下载；GitHub Release 发布工作流只编译、打包和上传程序，不下载模型。

</details>
