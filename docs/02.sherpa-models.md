# Sherpa-onnx 内置模型

服务端使用 `org.k2fsa.sherpa.onnx`。所有内置模型均通过 `SelectedSettings` 选择，模型目录固定为：

```text
models/{vad|asr|tts}/{模型名-kebab-case}/
```

不要直接沿用上游压缩包内的文件名；请按下表重命名后放入目录。这样配置不需要暴露任意本地文件路径，模型缺文件时日志会指出确切缺失项。

通用运行时配置可写入任一模型的配置项：`Provider`（默认 `cpu`）、`NumThreads`、`Debug`。未列出的推理参数会使用 sherpa-onnx 默认值。

## VAD

| 配置名 | 目录 | 必需文件 | 常用配置 |
| --- | --- | --- | --- |
| `Silero` | `models/vad/silero` | `model.onnx` | `Threshold`、`SilenceThresholdSecond`、`MinSpeechDurationSecond`、`MaxSpeechDurationSecond` |
| `TenVad` | `models/vad/ten-vad` | `model.onnx` | 同上；`WindowSize` 默认 256 |

VAD 输入固定为 16 kHz 单声道。TenVad 的处理帧大小会自动采用 `WindowSize`，不会再沿用 Silero 的 512 样本帧。

## 流式 ASR

| 配置名 | 目录 | 必需文件 |
| --- | --- | --- |
| `OnlineTransducer` | `models/asr/online-transducer` | `encoder.onnx`、`decoder.onnx`、`joiner.onnx`、`tokens.txt` |
| `OnlineParaformer` | `models/asr/online-paraformer` | `encoder.onnx`、`decoder.onnx`、`tokens.txt` |
| `OnlineZipformer2Ctc` | `models/asr/online-zipformer2-ctc` | `model.onnx`、`tokens.txt` |
| `OnlineNemoCtc` | `models/asr/online-nemo-ctc` | `model.onnx`、`tokens.txt` |
| `OnlineToneCtc` | `models/asr/online-tone-ctc` | `model.onnx`、`tokens.txt` |

流式模型自动复用既有的 `AudioReceiveHandler` 处理流程：每个会话的每次话语都会创建一个 `OnlineStream`，音频到达后解码，VAD 结束话语后调用 `InputFinished` 并返回最终转写。无需改变 XiaoZhi 客户端协议。可选配置有 `DecodingMethod`、`MaxActivePaths`、`EnableEndpoint`、`Rule1MinTrailingSilence`、`Rule2MinTrailingSilence`、`Rule3MinUtteranceLength` 与 `HotwordsScore`；如目录内存在 `hotwords.txt` 会自动启用。

## 使用与验证

示例配置已预置所有模型的空配置项。把 `SelectedSettings` 对应项改成上表的配置名，放好模型文件后启动即可，例如：

```json
"SelectedSettings": {
  "VAD": "TenVad",
  "ASR": "OnlineParaformer",
  "TTS": "ZipVoice"
}
```

仓库不提交预训练模型。完成文件准备后，先运行 `dotnet build XiaoZhi.Net.sln --nologo`，再以实际 XiaoZhi 设备完成一次说话、识别与播放的烟雾测试。共享 sherpa native 实例在运行时每个类别只预构建一个；远程私有配置只能复用该当前选中模型，避免会话间重建或互相覆盖。
