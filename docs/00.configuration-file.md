# 配置文件参考

下一篇：[01-扩展自定义模型](01.extend-custom-model.md)
<hr />

当前文档用于描述示例 Sample 服务器 `XiaoZhi.Net.Sample.Server` 读取的 `config*.json`。字段含义以当前配置绑定代码、配置类和 Provider 实现为准。

> [!TIP]
> 本项目中使用的示例 json 文件只是一种可读性较好的配置方式，开发者亦可以使用其他符合要求的配置方式并解析成 `XiaoZhiConfig` 类后传入 `ServerBuilder`。
> 此文档都以当前的示例 json 文件作为参考。

## 配置文件概览

| 类别 | 文件 | 用途 |
| --- | --- | --- |
| 基础配置 | `config.json` | 协议、提示词、WebSocket、日志、音频、设备绑定与 MCP 基础配置。 |
| VAD 配置 | `config_vad.json` | 选择语音活动检测 Provider，并配置断句与静音检测参数。 |
| ASR 配置 | `config_asr.json` | 选择语音识别 Provider，并配置本地推理或云端识别参数。 |
| TTS 配置 | `config_tts.json` | 选择语音合成 Provider，并配置音色、语速及音频保存参数。 |
| LLM 配置 | `config_llm.json` | 配置并选择聊天模型。 |
| RAG 配置 | `config_rag.json` | 配置并选择知识库使用的 Embedding 模型，以及检索参数。 |
| 意图识别配置 | `config_intent.json` | 选择关闭工具调用、独立 LLM 意图识别或聊天模型 Function Call 模式。 |

## 基础配置

以下字段位于 `config.json` 根节点。标记“示例未列出”的字段可由当前配置类绑定，但示例文件没有填写。

| 属性名 | 类型 | 必填条件 | 代码默认值 | 作用与注意事项 |
| --- | --- | --- | --- | --- |
| `Protocol` | string | 否 | `webSocket` | 实际协议选择属性。当前仅实现 webSocket；选择 `Mqtt` 会抛出不支持异常。 |
| `Prompt` | string | 否 | 空字符串 | 聊天模型的系统提示词；由管理层注入选中的聊天 Agent。 |
| `AuthEnabled` | boolean | 否 | `false` | 是否开启登录验证； <br />启用后需实现 `IBasicVerify` 接口后并调用 `WithVerify` 方法进行注册。 |
| `WebSocketServerOption` | object | 否 | 配置类默认实例 | WebSocket 服务监听配置，字段见下表。 |
| `LogSetting` | object | 否 | 配置类默认实例 | 控制日志级别、控制台输出与日志文件。 |
| `AudioSetting` | object | 是 | 无（属性初始化为 null） | 默认设备音频与服务音频配置；应提供此节点。 |
| `DeviceBindSetting` | object | 否 | 配置类默认实例 | 绑定提示与绑定码播报音频位置。 |
| `McpSettings` | object | 否 | `null` | MCP 子客户端配置字典；示例为空对象，当前为空或缺省时构建设备 MCP 客户端。 |
| `MusicProviderSetting` | object | 否 | 配置类默认实例 | 音乐目录与播放控制等待时间。 |

### WebSocket 监听

| 属性名 | 类型 | 必填条件 | 代码默认值 | 作用与注意事项 |
| --- | --- | --- | --- | --- |
| `WebSocketServerOption.IP` | string | 否 | `0.0.0.0` | 监听地址；`0.0.0.0` 表示监听所有 IPv4 网卡。 |
| `WebSocketServerOption.Port` | integer | 否 | `4530` | 监听端口，应选择本机可用端口。 |
| `WebSocketServerOption.Path` | string | 否 | `/xiaozhi/v1/` | WebSocket 连接路径。 |
| `WebSocketServerOption.WssOption` | object | 否 | `null` | 提供此节点时加载服务器证书，用于 WSS。 |
| `WebSocketServerOption.WssOption.CertFilePath` | string | 启用 WSS 时 | 空字符串 | 服务器证书文件路径；启用 WSS 时必须指向可读取证书。 |
| `WebSocketServerOption.WssOption.CertPassword` | string / null | 否 | `null` | 证书密码；仅在证书需要密码时填写。 |

### 日志

| 属性名 | 类型 | 必填条件 | 代码默认值 | 作用与注意事项 |
| --- | --- | --- | --- | --- |
| `LogSetting.LogLevel` | string | 否 | `INFO` | 最小日志级别；<br />可选值 `VERB`、`DEBUG`、`INFO`、`WARN`、`ERROR`、`FATAL`，忽略大小写，其他值回退为 INFO。 |
| `LogSetting.LogFilePath` | string | 否 | `logs/server_log.log` | 日志文件路径，日志按天滚动。 |
| `LogSetting.OutputTemplate` | string | 否 | `{Timestamp:yyyy-MM-dd HH:mm:ss} [{Level:u4}] {Message:lj}{NewLine}{Exception}` | Serilog 输出模板，应用于日志文件及控制台。 |
| `LogSetting.RetainedFileCountLimit` | integer | 否 | `7` | 滚动日志保留的文件数量上限，由 Serilog 文件输出器处理。 |

### 音频

| 属性名 | 类型 | 必填条件 | 代码默认值 | 作用与注意事项 |
| --- | --- | --- | --- | --- |
| `AudioSetting.Format` | string | 否 | `opus` | 默认设备音频格式；当前 hello 协商仅接受 Opus。 |
| `AudioSetting.SampleRate` | integer | 否 | `16000` | 默认音频采样率，单位 Hz。设备 hello 支持 8000、12000、16000、24000、48000 Hz。 |
| `AudioSetting.Channels` | integer | 否 | `1` | 声道数；当前设备 hello 只接受单声道。 |
| `AudioSetting.FrameDuration` | integer | 否 | `60` | 每帧时长，单位毫秒。设备 hello 支持 10、20、40、60 ms。 |

设备 hello 中的 `audio_params` 可更新该会话的输入音频参数。

> [!NOTE]
> 服务端内部的音频处理流水线的 VAD 与 ASR 都是以重采样后的 **16000 Hz、单声道** PC进行处理的。

### 设备绑定音频

| 属性名 | 类型 | 必填条件 | 代码默认值 | 作用与注意事项 |
| --- | --- | --- | --- | --- |
| `DeviceBindSetting.BindCodePromptFilePath` | string | 否 | `configs/assets/bind_code.wav` | 绑定码播报前的提示音频文件路径。 |
| `DeviceBindSetting.BindCodeDigitFolderPath` | string | 否 | `configs/assets/bind_code` | 绑定码数字音频目录，必须恰好包含 10 个可解码音频文件，文件名（不含扩展名）分别为 0～9；示例使用 `0.wav` 至 `9.wav`。注意代码默认目录与示例的 `Configs/assets/bind_codes` 不同。 |
| `DeviceBindSetting.BindNotFoundFilePath` | string | 否 | `configs/assets/bind_not_found.wav` | 未找到设备绑定信息时播放的音频文件路径。 |

### MCP

| 属性名 | 类型 | 必填条件 | 代码默认值 | 作用与注意事项 |
| --- | --- | --- | --- | --- |
| `McpSettings.<客户端键>` | object | 否 | 无 | 子客户端的 `ModelSetting` 对象。管理层识别 `DeviceMcpClient`、`McpEndpointClient`、`ServerMcpClient` 键；可用性限制见下文。 |
| `McpSettings.<客户端键>.ModelName` | string | 否 | `null` | 配置对象的模型名；当前 MCP 构建按字典键及客户端自身的 ModelName 查找，此属性不能替代正确的客户端键。 |
| `McpSettings.<客户端键>.Config` | object | 否 | 空字典 | 子客户端参数字典，结构化参数兼容 JSON 对象及 JSON 字符串。 |
| `McpSettings.McpEndpointClient.Config.EndpointUrl` | string | 否 | `null` | 【示例未列出】端点客户端实现读取的 WebSocket URL；空值时不建立连接。当前主链路接入存在限制。 |
| `McpSettings.McpEndpointClient.Config.Headers` | object | 否 | `null` | 【示例未列出】端点连接使用的请求头字典，值为字符串；鉴权值使用自行提供的凭据。 |

空 `McpSettings` 会使用设备 MCP 默认配置；设备需在 hello 中声明 MCP 能力才进入相应初始化。非空配置不会自动补齐 `DeviceMcpClient` 键。当前 `McpClient.Build` 将端点客户端键关联到了设备客户端实例，`ServerMcpClient` 仍是占位实现，不能将这些配置写成已经可用的服务端 MCP 功能。本文仅说明现有配置结构，不提供将其作为可用功能的接入示例。

| 属性名 | 类型 | 必填条件 | 代码默认值 | 作用与注意事项 |
| --- | --- | --- | --- | --- |
| `MusicProviderSetting.MusicFolderPath` | string | 否 | `./musics` | 本地音乐文件目录。 |
| `MusicProviderSetting.CommandTimeoutSeconds` | int | 否 | `5` | 音乐控制命令的最长等待时间，单位秒，必须大于零。 |

## 模型选择与参数格式

`SelectedSettings` 存放各类别选中的配置名称，`ConfiguredSettings` 存放该类别下的所有配置。未选中的配置不表示服务会使用它；但管理层也会遍历配置进行注册，部分无效配置仍可能导致启动失败。

| 属性名 | 类型 | 必填条件 | 代码默认值 | 作用与注意事项 |
| --- | --- | --- | --- | --- |
| `SelectedSettings` | object | 默认会话链路需要 | 空字典 | 类别到配置名称的映射。 |
| `SelectedSettings.VAD` | string | 是 | 无 | 引用 `ConfiguredSettings.VAD` 下的名称。 |
| `SelectedSettings.ASR` | string | 是 | 无 | 引用 `ConfiguredSettings.ASR` 下的名称。 |
| `SelectedSettings.TTS` | string | 是 | 无 | 引用 `ConfiguredSettings.TTS` 下的名称。 |
| `SelectedSettings.LLM` | string | 是 | 无 | 引用 `ConfiguredSettings.LLM` 下的聊天配置。 |
| `SelectedSettings.Intent` | string | 是 | 无 | 引用 `ConfiguredSettings.Intent` 下的模式配置；关闭意图也应选择 `None`。 |
| `SelectedSettings.RAG` | string | 可选 | 无 | 引用 `ConfiguredSettings.RAG` 下的配置名称，核心检索和示例导入器使用同一份向量模型配置。 |
| `ConfiguredSettings` | object | 是 | 空字典 | 结构为“类别 → 配置名称 → 参数字典”。 |
| `ConfiguredSettings.<类别>.<名称>` | object | 被引用时 | 无 | 对应 Provider 的参数；具体字段见后续表格。 |

> [!TIP]
> `SelectedSettings` 表示当前模型类型默认选择的模型名称，`ConfiguredSettings` 则列出所有可用的模型配置。
> 在 `ConfiguredSettings` 中配置的模型文件，以约定的方式将模型文件存放于 `./{models}/{模型类型}/{小写 Kebab-Case 规范的模型名称}` 目录下，可以参考已有的 `Sherpa` 模型示例。
> 云厂商模型不受此条件限制。

例如，配置一个使用 `Qwen` LLM 模型：

```json
{
  "SelectedSettings": {
    "LLM": "Qwen"
  },
  "ConfiguredSettings": {
    "LLM": {
      "Qwen": {
        "BaseUrl": "https://your-openai-compatible-host/v1",
        "ApiKey": "<YOUR_API_KEY>",
        "ModelName": "<YOUR_CHAT_MODEL>",
        "Type": "chat"
      }
    }
  }
}
```

## VAD：语音活动检测

<details>
<summary>展开 VAD 配置</summary>

配置文件：[`config_vad.json`](../demo/XiaoZhi.Net.Sample.Server/Configs/config_vad.json)。

检测输入语音的开始、结束与长期静音，帮助断句。三种实现均在本地运行，当前 `SampleRate` 必须为 16000 Hz，否则构建失败。

### Silero

基于 Sherpa ONNX 的本地 Silero VAD，使用固定 512 个采样点的分析帧。

配置位置：`ConfiguredSettings.VAD.Silero`。实现参考：[Silero.cs](../src/server/XiaoZhi.Net.Server/Server/Providers/VAD/Sherpa/Silero.cs)。

| 属性名 | 类型 | 必填条件 | 代码默认值 | 作用与注意事项 |
| --- | --- | --- | --- | --- |
| `SampleRate` | integer | 否 | `16000` | VAD 处理采样率，单位 Hz；当前必须为 16000。 |
| `NumThreads` | integer | 否 | `1` | 本地模型推理线程数。 |
| `Provider` | string | 否 | `cpu` | Sherpa 推理执行后端；其他后端是否可用取决于安装的运行时与平台。 |
| `Debug` | integer | 否 | `0` | Sherpa 调试开关，0 关闭、1 开启。 |
| `Threshold` | number | 否 | `0.5` | 语音判定阈值；SileroNative 用它判断进入语音状态，Sherpa 实现直接传给模型。 |
| `SilenceThresholdSecond` | number | 否 | `0.7` | 结束一段语音前要求的静音时长，单位秒。 |
| `MinSpeechDurationSecond` | number | 否 | `0.5` | Sherpa 判为有效语音的最短持续时间，单位秒。 |
| `MaxSpeechDurationSecond` | number | 否 | `60.0` | Sherpa 单段语音的最长持续时间，单位秒。 |
| `CloseConnectionNoVoiceTime` | integer | 否 | `120000` 毫秒 | 触发长期静音回调的等待时长，单位统一为毫秒；默认等待两分钟。播放或会话处理期间被丢弃的音频不计入该时长，恢复监听后重新计时。 |

### SileroNative

直接通过 ONNX Runtime 执行本地 Silero 模型，以双阈值和静音持续时间控制断句，分析帧为 512 个采样点。

配置位置：`ConfiguredSettings.VAD.SileroNative`。实现参考：[SileroNative.cs](../src/server/XiaoZhi.Net.Server/Server/Providers/VAD/Native/SileroNative.cs)。

| 属性名 | 类型 | 必填条件 | 代码默认值 | 作用与注意事项 |
| --- | --- | --- | --- | --- |
| `SampleRate` | integer | 否 | `16000` | VAD 处理采样率，单位 Hz；当前必须为 16000。 |
| `SilenceThresholdSecond` | number | 否 | `0.7` | 结束一段语音前要求的静音时长，单位秒。 |
| `Threshold` | number | 否 | `0.5` | 语音判定阈值；SileroNative 用它判断进入语音状态，Sherpa 实现直接传给模型。 |
| `ThresholdLow` | number | 否 | `0.2` | 已进入语音状态后，判定回到静音的较低阈值，配合 Threshold 形成双阈值判断。 |
| `CloseConnectionNoVoiceTime` | integer | 否 | `120000` 毫秒 | 触发长期静音回调的等待时长，单位统一为毫秒；默认等待两分钟。播放或会话处理期间被丢弃的音频不计入该时长，恢复监听后重新计时。旧版按秒配置的值需乘以 1000 后迁移，例如 120 应改为 120000。 |

### TenVad

基于 Sherpa ONNX 的本地 TenVad，分析窗口大小可配置。

配置位置：`ConfiguredSettings.VAD.TenVad`。实现参考：[TenVad.cs](../src/server/XiaoZhi.Net.Server/Server/Providers/VAD/Sherpa/TenVad.cs)。

| 属性名 | 类型 | 必填条件 | 代码默认值 | 作用与注意事项 |
| --- | --- | --- | --- | --- |
| `SampleRate` | integer | 否 | `16000` | VAD 处理采样率，单位 Hz；当前必须为 16000。 |
| `NumThreads` | integer | 否 | `1` | 本地模型推理线程数。 |
| `Provider` | string | 否 | `cpu` | Sherpa 推理执行后端；其他后端是否可用取决于安装的运行时与平台。 |
| `Debug` | integer | 否 | `0` | Sherpa 调试开关，0 关闭、1 开启。 |
| `Threshold` | number | 否 | `0.5` | 语音判定阈值；SileroNative 用它判断进入语音状态，Sherpa 实现直接传给模型。 |
| `SilenceThresholdSecond` | number | 否 | `0.5` | 结束一段语音前要求的静音时长，单位秒。 |
| `MinSpeechDurationSecond` | number | 否 | `0.25` | Sherpa 判为有效语音的最短持续时间，单位秒。 |
| `MaxSpeechDurationSecond` | number | 否 | `5.0` | Sherpa 单段语音的最长持续时间，单位秒。 |
| `WindowSize` | integer | 否 | `256` | TenVad 每个分析窗口的采样点数，同时决定 Provider 的输入帧长。 |
| `CloseConnectionNoVoiceTime` | integer | 否 | `120000` 毫秒 | 触发长期静音回调的等待时长，单位统一为毫秒；默认等待两分钟。播放或会话处理期间被丢弃的音频不计入该时长，恢复监听后重新计时。 |

</details>

## ASR：语音识别

<details>
<summary>展开 ASR 配置</summary>

配置文件：[`config_asr.json`](../demo/XiaoZhi.Net.Sample.Server/Configs/config_asr.json)。

本地 Sherpa 离线识别等待完整语音片段后处理；Online 系列和云端实时实现支持持续输入音频。所有 ASR 输入已统一为 16000 Hz 单声道 PCM。离线热词文件存在时使用 modified_beam_search，否则使用 greedy_search；热词支持仍取决于具体模型。

### SenseVoice

本地离线 SenseVoice 语音识别，可控制逆文本规范化。

配置位置：`ConfiguredSettings.ASR.SenseVoice`。实现参考：[SenseVoice.cs](../src/server/XiaoZhi.Net.Server/Server/Providers/ASR/Sherpa/SenseVoice.cs)。

| 属性名 | 类型 | 必填条件 | 代码默认值 | 作用与注意事项 |
| --- | --- | --- | --- | --- |
| `NumThreads` | integer | 否 | `1` | 本地模型推理线程数。 |
| `Provider` | string | 否 | `cpu` | Sherpa 推理执行后端；其他后端是否可用取决于安装的运行时与平台。 |
| `Debug` | integer | 否 | `0` | Sherpa 调试开关，0 关闭、1 开启。 |
| `UseInverseTextNormalization` | integer | 否 | `1` | 模型逆文本规范化开关，0 关闭、1 开启；用于将口语形式转为书面形式。 |
| `HotwordsFile` | string | 否 | `null` | 热词文件名，按模型目录拼接路径；非空时开启 modified_beam_search。模型是否支持热词由 Sherpa 决定。 |
| `HotwordsScore` | number | 否 | `1.5` | 热词加分权重；离线仅在 HotwordsFile 非空时读取，流式仅在模型目录存在 hotwords.txt 时读取。 |
| `MaxActivePaths` | integer | 否 | `4` | 束搜索最大活跃路径数；离线仅在 HotwordsFile 非空时读取，greedy_search 下通常无作用。 |
| `MaxBatchSize` | integer | 否 | `10` | 离线识别后台单次最多合批的请求数，应填写正整数。 |
| `BatchWaitTimeMs` | integer | 否 | `20` | 离线合批额外等待时间，单位毫秒；大于 0 才等待更多请求。 |
| `FileSavingOption` | object | 否 | 关闭保存 | 音频文件保存配置；可写为 JSON 对象，也兼容序列化后的 JSON 字符串。 |
| `FileSavingOption.SaveFile` | boolean | 否 | `false` | 是否保存音频；ASR 保存待识别音频，TTS 保存合成音频。 |
| `FileSavingOption.SavePath` | string | 否 | `./data/audio-cache` | 保存目录，相对路径基于进程工作目录；开启保存时应为有效目录。 |
| `FileSavingOption.Format` | string | 否 | `wav` | 保存文件的扩展名，由音频编辑器按扩展名选择格式；可用格式取决于媒体实现。 |
| `FileSavingOption.SampleRate` | integer | 否 | `16000` | 当前 ASR 保存调用使用音频编辑器的默认 16000 Hz，未使用此字段。 |
| `FileSavingOption.Channels` | integer | 否 | `1` | 记录类型中的声道数；当前保存调用固定使用单声道，未使用此字段。 |
| `FileSavingOption.BitRate` | integer | 否 | `128000` | 记录类型中的码率，单位 bit/s；当前保存调用固定使用 128000，未使用此字段。 |

### Paraformer

本地离线 Paraformer 语音识别，按完整语音片段进行推理。

配置位置：`ConfiguredSettings.ASR.Paraformer`。实现参考：[Paraformer.cs](../src/server/XiaoZhi.Net.Server/Server/Providers/ASR/Sherpa/Paraformer.cs)。

| 属性名 | 类型 | 必填条件 | 代码默认值 | 作用与注意事项 |

## Intent：意图识别与工具调用

<details>
<summary>展开 Intent 配置</summary>

配置文件：[`config_intent.json`](../demo/XiaoZhi.Net.Sample.Server/Configs/config_intent.json)。

这些是对话工作流模式，不是独立的语音模型。SelectedSettings.Intent 引用外层名称，具体执行行为由对应配置的 Type 决定。工具仍需通过现有 Function Tool/MCP 注册流程提供；选择模式不会自动创建工具。

### None

关闭意图识别及聊天模型工具调用，直接使用已选择的聊天模型回复。

配置位置：`ConfiguredSettings.Intent.None`。

| 属性名 | 类型 | 必填条件 | 代码默认值 | 作用与注意事项 |
| --- | --- | --- | --- | --- |
| `Type` | string | 否 | `None` | 此模式应填写 None；缺省按 None 处理。None 关闭工具调用，IntentLlm 使用独立意图工作流，FunctionCall 由聊天模型调用工具。 |

### IntentLlm

使用指定的云端聊天模型先识别工具意图，再执行工具并生成回复；未识别到工具意图时回到主聊天模型。

配置位置：`ConfiguredSettings.Intent.IntentLlm`。
| 属性名 | 类型 | 必填条件 | 代码默认值 | 作用与注意事项 |
| --- | --- | --- | --- | --- |
| `Type` | string | 否 | `None` | 此模式应填写 IntentLlm；缺省按 None 处理。None 关闭工具调用，IntentLlm 使用独立意图工作流，FunctionCall 由聊天模型调用工具。 |
| `LLM` | string | Type 为 IntentLlm 时 | 无 | 引用 ConfiguredSettings.LLM 下的聊天配置名称；同时用于意图识别与工具结果回复，不要求与主聊天选择一致。 |

### FunctionCall

由主聊天模型通过 Function Call 自动选择与调用已注册工具；需要模型和服务端支持工具调用。

配置位置：`ConfiguredSettings.Intent.FunctionCall`。

| 属性名 | 类型 | 必填条件 | 代码默认值 | 作用与注意事项 |
| --- | --- | --- | --- | --- |
| `Type` | string | 否 | `None` | 此模式应填写 FunctionCall；缺省按 None 处理。None 关闭工具调用，IntentLlm 使用独立意图工作流，FunctionCall 由聊天模型调用工具。 |

</details>
