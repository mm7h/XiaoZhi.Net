# Sherpa 模型下载

本项目内置模型的官方下载源是 [k2-fsa/sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) 的 GitHub Releases：ASR 和 VAD 位于 [asr-models](https://github.com/k2-fsa/sherpa-onnx/releases/tag/asr-models)，TTS 位于 [tts-models](https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models)。下表是与当前 Provider 文件约定相匹配的一组 CPU 模型，不包含 Ascend、RKNN、QNN 等硬件专用包。

项目模型目录及必需文件见 [02.sherpa-models.md](02.sherpa-models.md)。上游压缩包中的文件名不完全一致；下载脚本会将其整理为项目要求的名称。

## 使用脚本

脚本位于 [Download-SherpaModels.ps1](../scripts/Download-SherpaModels.ps1)。未指定模型时只显示列表，不会下载任何内容。

```powershell
# 下载指定模型到仓库 models 目录
pwsh -File .\scripts\Download-SherpaModels.ps1 -Models Silero,OnlineParaformer,Kokoro

# 下载全部模型；模型总量很大，请先确认网络和磁盘空间
pwsh -File .\scripts\Download-SherpaModels.ps1 -All

# 下载到自定义目录，并保留下载的压缩包
pwsh -File .\scripts\Download-SherpaModels.ps1 -Models SenseVoice -Destination D:\XiaoZhiModels -KeepArchives
```

目标目录已有完整模型时，脚本会跳过它。目录不完整时，脚本会停止以保护已有文件；确认需要重新下载时，显式添加 `-Force`。

ZipVoice 和 Pocket 需要用户自行放入有权使用的参考音频 `reference.wav`；ZipVoice 还需要对应文本 `reference.txt`。脚本不会复制上游测试音频作为服务的默认音色。`reference.wav` 必须是 16 位、单声道 PCM WAV。
